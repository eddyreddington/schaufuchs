Neue Entscheidung: nächste Nummer, `NNN-titel.md`, 5–15 Zeilen (Stand, Kontext, Entscheidung, Folgen, Wo). Eine geänderte
Entscheidung bekommt eine neue Datei; die alte erhält „Stand: ersetzt durch NNN“.
